## Анимации в Compose

Тут будут собраны способы анимации UI в Jetpack Compose

#### Типы анимаций в Compose

Инструменты анимаций можно поделить на два слоя:
- **Низкоуровневые:** дают полное управление над анимацией: как она меняется по кадрам, кто управляет, корутины, запуск, прерывания 
- **Высокоуровневые:** готовые composable-обёртки. Под капотом используют низкоуровневые анимации. Более просты в использовании, берут на себя рутину запуска, прерываний и тд.

Первые дают свободу действий  и гибкость - вторые стандартные но легки в использовании.

#### Высокоуровневые анимации

- ***Animated Visibility*** / Скрыть, показать, сменить Composable объект целиком

- ***Animated Content*** / Переключение контента (к примеру между состоянием загрузки, ошибки, контента).

- ***Crossfade*** / Простой fade между экранами. 

- Modifier ***.animateContentSize*** / Изменение размера контейнера при изменении текста внутри


##### Animated Content *vs* Animated Visibility *vs* Crossfade

Crossfade и Animated Content похожи по своей сути. Только первый использует плавный переход и максимально простой, а второй более гибкий для настройки (может включать в себя выдвижения слева/сверху/снизу и тд)

Animated Visibility нужен для скрытия/появления объекта целиком.
